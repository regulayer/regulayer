```python
from openai import OpenAI

client = OpenAI(
    # 1. Preserve the target API Key.

    # 2. Reroute the Base URL to the Regulayer Gateway.
    base_url="https://api.regulayer.tech/v1",
    
    # 3. Inject the Regulayer Authentication Header.

    model="gpt-4o",
    messages=[{"role": "user", "content": "Analyze these financial records."}],
)
```

PART 3: TYPESCRIPT / JAVASCRIPT INTEGRATION (OpenAI SDK)
================================================================================
```typescript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,    
  baseURL: "https://api.regulayer.tech/v1", // Route to Regulayer
  defaultHeaders: {
    "X-Regulayer-Api-Key": process.env.REGULAYER_PROJECT_KEY,
  }
});

export async function askAI(userQuery: string) {
    const completion = await client.chat.completions.create({
      messages: [{ role: "user", content: userQuery }],
      model: "gpt-4-turbo",
    });
    return completion.choices[0].message;
}
```

PART 4: EXCEPTION HANDLING AND THE HUMAN-IN-THE-LOOP MECHANIC
================================================================================
Because Regulayer enforces compliance, it can explicitly block or pause an API call mid-flight. As an AI developer, your code MUST handle these explicit HTTP responses so the client application does not crash.

<CODE_403_FORBIDDEN_BLOCK>
Reason: An enterprise policy evaluated the payload and explicitly blocked it (e.g., detected PII).
Action: You must wrap the LLM call in a `try/catch` block. Catch the 403 Forbidden exception and gracefully return a string to the user like "Action blocked by compliance policy."
</CODE_403_FORBIDDEN_BLOCK>

<CODE_202_ACCEPTED_HUMAN_PAUSE>
Reason: The Regulayer policy triggered a "Human-in-the-Loop" requirement. Regulayer suspended the HTTP proxy request and sent it to the web dashboard queue where a human Compliance Officer must click "Approve". 
Action: To prevent the HTTP request from timing out while waiting for a human, Regulayer immediately returns an `HTTP 202 Accepted`. The response body contains a JSON payload: `{"status": "pending_review", "governance_ticket_id": "<UUID>"}`.

Your application code MUST catch the 202 response, enter an asynchronous loop, and poll the Regulayer status API (`GET https://api.regulayer.tech/v1/governance/status/<UUID>`) every few seconds until the Human approves it (returning `status: resolved_compliant`) or rejects it (returning `status: resolved_rejected`).
</CODE_202_ACCEPTED_HUMAN_PAUSE>

Execute flawless code integrations. Focus heavily on catching 403 Blocks and 202 Polling handling when rewriting user applications.
