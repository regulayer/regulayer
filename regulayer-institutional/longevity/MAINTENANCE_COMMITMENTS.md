# Maintenance Commitments

**Our Promise to the Ecosystem**

1.  **No Backward Incompatibility**: Future versions of the Verifier MUST verify proofs generated by v1.0.
2.  **No Retroactive Invalidation**: We will never revoke a standard retrospectively unless a foundational cryptographic break (e.g., SHA-256 collision) occurs.
3.  **Open Source Verification**: The reference verifier (Python/Rust) will ALWAYS remain Open Source (MIT/Apache 2.0). We will never close-source the tool needed to check our work.
