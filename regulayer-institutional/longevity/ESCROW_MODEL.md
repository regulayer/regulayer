# Institutional Escrow Model

**Preserving the Standard for Posterity**

subsection: **What is Escrowed?**
1.  **The Specification**: PDF and Markdown copies of the Evidence Standard.
2.  **The Reference Verifier**: Source code for `regulayer-verifier` and `regulayer-reproduction`.
3.  **The Root TRUST Bundle**: Public keys of the Root CAs.

subsection: **Escrow Agents**
- **GitHub Archive Program**: Code deposited in Arctic Code Vault.
- **Internet Archive**: Docs mirrored to WayBack Machine.
- **Partner Universities**: Code shared with academic partners in "Cold Storage".

**Trigger Condition**: If Regulayer Inc. domains go offline for >90 days, the Escrow Agents are authorized to republish the materials as Public Domain.
