# Change Authority

**Governance of the Regulayer Standard**

## Proposing Changes
Changes to the Proof Schema or Verification Logic must follow the **RFC (Request for Comments)** process.
1. Draft Proposal
2. Community Review (30 Days)
3. Security Review (External Audit)
4. Ratification

## Veto Power
Any change that breaks **Backward Compatibility** for existing proofs is subject to automatic Veto, unless required for critical security (e.g., algorithm obsolescence).

## Who Decides?
Currently: Regulayer Technical Steering Committee.
Future Goal: Federated Consortium (Regulators + Industry + Academia).
