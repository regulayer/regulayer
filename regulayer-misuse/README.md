# Regulayer Misuse Resistance

**Proactive Defense Against Abuse**

This module documents how Regulayer resists being used for deception, "trust washing", or audit theater.

## Components
- **Catalog**: Known patterns of deceit (`MISUSE_CATALOG.md`).
- **Defenses**: Why the system defaults to "NO" (`DEFENSIVE_DEFAULTS.md`).
- **Constraints**: Rules for specific human roles (`SALES_MISUSE.md`, etc.).

## Philosophy
A trust system that allows itself to be misused is not a trust system; it is a deception accomplice. We explicitly refuse that role.
