# Regulayer Citation Control

**Preventing Interpretive Drift**

This module provides the "Style Guide for Truth." It ensures that when the world talks about Regulayer, they talk about the same thing we built, not a fantasy version of it.

## Key Mechanisms
- **Canon**: The exact words to use.
- **Precedent Limits**: Stopping courts from inventing new powers for us.
- **Versioning**: Ensuring citations age gracefully.

## Goal
To ensure that a citation in 2030 means exactly what it meant in 2025.
