# Audit Readiness Checklist

Version: 1.0.0  
Use: Before any regulatory examination

---

## Pre-Audit Verification

### Offline Verification
- [ ] Regulator can verify without Regulayer API access
- [ ] Verification tool is available for download
- [ ] Tool documentation is current
- [ ] Test verification works on sample bundle

### Evidence Completeness
- [ ] All decisions in scope are exportable
- [ ] Submission packages can be generated
- [ ] Chain integrity reports are available
- [ ] Governance evidence is exportable (if requested)

### Boundary Documentation
- [ ] Disclaimers are present on all reports
- [ ] "What we prove" is clearly stated
- [ ] "What we don't prove" is clearly stated
- [ ] Legal boundaries are explicit

---

## Artifact Readiness

### Proof Bundles
- [ ] Decision proof bundles exportable
- [ ] Record hashes verifiable
- [ ] Chain links verifiable
- [ ] Attestations verifiable

### Reports
- [ ] System Trust Report available
- [ ] Decision Trust Reports available
- [ ] Chain Integrity Reports available
- [ ] All include disclaimers

### Submission Packages
- [ ] Manifest lists all files
- [ ] All files hash-verified
- [ ] Cover letter included
- [ ] README included

---

## Personnel Readiness

### Technical Support
- [ ] Engineer available to demonstrate verification
- [ ] Can explain hash chain to non-technical audience
- [ ] Can run offline verification live

### Legal Support
- [ ] Counsel briefed on limitations
- [ ] Counsel has reviewed disclaimers
- [ ] Counsel understands boundary between integrity and correctness

---

## Response Preparedness

### Common Questions
- [ ] "How do I verify independently?" - Answer ready
- [ ] "What if you go out of business?" - Answer ready
- [ ] "What about key compromise?" - Answer ready
- [ ] "What don't you prove?" - Answer ready

### Failure Scenarios
- [ ] Incident disclosure process documented
- [ ] Trust degradation policy documented
- [ ] Affected vs unaffected scoping documented

---

## Final Check

- [ ] All items above verified within last 30 days
- [ ] No changes to system since last verification
- [ ] Audit response team identified
- [ ] Contact information current
