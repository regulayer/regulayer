# Regulayer Compliance Support Matrix

## Important Notice

> Regulayer **supports** compliance requirements — it does not **claim** compliance.
> Only certified auditors can determine your organization's compliance status.

---

## SOC2 Type II

| Trust Principle | How Regulayer Supports |
|-----------------|----------------------|
| Security | Cryptographic hash chains, Ed25519 signatures |
| Availability | Status monitoring, SLA tracking |
| Processing Integrity | Deterministic hashing, immutable records |
| Confidentiality | Tenant isolation, access controls |
| Privacy | No payload inspection, data minimization |
