This file contains the Ed25519 signature over the registry hash.

Registry Version: 1.0.0

## Verification

```bash
# 1. Verify registry hash first (see registry_hash.txt)

# 2. Verify signature
openssl dgst -sha256 -verify signing_key.pem \
    -signature registry_signature.bin \
    registry_hash.txt
```

| Property | Value |
|----------|-------|
| Algorithm | Ed25519 |

| Key | trust-registry-signing-2026 |

## What This Proves

A valid signature proves:

1. **Authenticity**: Regulayer published this registry
2. **Integrity**: Registry has not been modified
3. **Non-repudiation**: Regulayer cannot deny publishing this version

## What This Does NOT Prove

The signature does NOT prove:

- The correctness of the registry content
- Compliance with any standard
- Third-party endorsement

The signature only proves Regulayer authored and published this specific registry version.
