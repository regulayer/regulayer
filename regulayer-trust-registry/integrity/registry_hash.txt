## Verification Script

```python
import hashlib
import json
from pathlib import Path

files = [
    "TRUST_MODELS.json",
    "AUDIT_VERSIONS.json",
    "SCHEMA_VERSIONS.json",
    "DEPRECATION_POLICY.json"
]

combined = b""
for f in files:
    content = Path(f).read_bytes()
    combined += content

computed_hash = hashlib.sha256(combined).hexdigest()
print(f"sha256:{computed_hash}")
```
