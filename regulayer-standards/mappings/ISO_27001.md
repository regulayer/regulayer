# ISO/IEC 27001 — Evidence Support Mapping

Version: 1.0.0  
Framework: ISO/IEC 27001:2022  
Document Type: Evidence Alignment (NOT Compliance Claim)

---

## Framework Overview

ISO 27001 specifies requirements for information security management systems (ISMS). This document maps Regulayer evidence capabilities to relevant ISO 27001 controls.

---

## A.5 — Organizational Controls

### A.5.1 Policies for Information Security

**What the standard asks:**  
Define and communicate information security policies.

**What Regulayer provides:**
- Immutable record of security-relevant decisions
- Policy enforcement via role-based access
- Audit trail of governance actions

**What Regulayer does NOT provide:**
- Policy document creation
- Policy communication
- Policy enforcement beyond Regulayer scope

**Evidence artifacts:**
- Access control audit logs
- Governance evidence exports

---

### A.5.23 Information Security for Cloud Services

**What the standard asks:**  
Manage security for cloud service usage.

**What Regulayer provides:**
- Cryptographic integrity of cloud-stored records
- Independent verification capability
- Offline evidence packages

**What Regulayer does NOT provide:**
- Cloud provider security assessment
- Data residency management
- Cloud configuration security

---

## A.8 — Asset Management

### A.8.10 Information Deletion

**What the standard asks:**  
Ensure secure deletion of information.

**What Regulayer provides:**
- APPEND-ONLY architecture (no deletion by design)
- Immutability guarantees for audit purposes
- Complete record preservation

**What Regulayer does NOT provide:**
- Data deletion capability (intentionally)
- Retention policy implementation beyond preservation

⚠️ **Note:** Regulayer is designed for immutable records. Deletion requests should be handled at the organizational level, not within Regulayer.

---

## A.9 — Access Control

### A.9.2 User Access Management

**What the standard asks:**  
Control user access to systems and information.

**What Regulayer provides:**
- Role-based access control (ANALYST, COMPLIANCE, AUDITOR, ADMIN)
- Segregation of duties enforcement
- Access action logging
- Conflict of interest checking

**What Regulayer does NOT provide:**
- User identity management
- Authentication mechanisms
- Access provisioning/deprovisioning

**Evidence artifacts:**
- Access control module documentation
- Governance access logs

---

## A.12 — Operations Security

### A.12.4 Logging and Monitoring

**What the standard asks:**  
Record and retain logs of security-relevant events.

**What Regulayer provides:**
- Immutable decision records
- Governance action logs
- Incident declaration logs
- Key rotation logs
- All logs append-only

**What Regulayer does NOT provide:**
- Infrastructure monitoring
- Alert management
- Log analysis tools

**Evidence artifacts:**
- All log exports are immutable
- Chain integrity reports

---

## A.14 — Cryptography

### A.14.1 Cryptographic Controls

**What the standard asks:**  
Use cryptography to protect information.

**What Regulayer provides:**
- SHA-256 for record hashing
- Ed25519 for digital signatures
- Hash chain for integrity verification
- Cryptographic snapshots for archival

**What Regulayer does NOT provide:**
- Key generation (uses customer keys)
- Key storage (references external KMS)
- Key lifecycle management beyond rotation logging

**Evidence artifacts:**
- Proof bundles with cryptographic details
- Cryptographic snapshot records
- CRYPTO_AGILITY_NOTE.md documentation

---

## A.18 — Compliance

### A.18.2 Information Security Reviews

**What the standard asks:**  
Conduct independent reviews of information security.

**What Regulayer provides:**
- Complete, verifiable audit trail
- Independent verification tools
- Offline verification capability
- Exportable evidence packages

**What Regulayer does NOT provide:**
- Security review methodology
- Review scheduling
- Findings management

**Evidence artifacts:**
- Submission packages
- Verification tool (open source)
