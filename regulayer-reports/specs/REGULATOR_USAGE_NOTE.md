# Regulator Usage Note

Version: 1.0.0  
Audience: Regulators, Auditors, Legal Counsel

---

## What You're Receiving

You have received a **Regulayer Trust Report**.

This is a static document that provides cryptographic evidence about AI decision records.

---

## What This Report Proves

### System Trust Report
- Describes how the Regulayer system is designed
- Explains the cryptographic guarantees claimed
- Lists operational assumptions

### Decision Trust Report
- Proves that a specific AI decision was recorded
- Proves the record has not been tampered with
- Proves who authorized the record (if attested)

### Chain Integrity Report
- Proves that the sequence of records is unbroken
- Identifies if and where tampering occurred

---

## What This Report Does NOT Prove

⚠️ **Critical Legal Boundary**

- **AI Correctness:** The AI's decision may be wrong. This report only proves it was recorded.
- **AI Fairness:** The AI may be biased. Recording does not imply fairness.
- **Legal Compliance:** This report is not a compliance certificate.
- **Business Appropriateness:** The decision may be inappropriate for the context.

---

## How to Use This Report

### For Audit Purposes

1. Verify the report was generated by Regulayer
2. Check the `integrity_status` field
3. Check the `attestation_status` field
4. Note the `disclaimers` section

### For Legal Proceedings

1. This report is evidence that a record exists
2. This report is evidence of record integrity
3. This report is NOT evidence of AI correctness
4. Consult legal counsel before relying on this report

### For Independent Verification

To independently verify the cryptographic claims:

1. Request the "Proof Bundle" for the decision
2. Use the `regulayer-proof-verifier` tool
3. The verifier operates offline without Regulayer access

---

## Archiving This Report

This report is designed for long-term archival:

- Self-contained (no external dependencies)
- Deterministic format (reproducible)
- Includes all necessary hashes

Store this report alongside the proof bundle for complete evidence.
