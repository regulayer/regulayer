# Regulayer Privacy Policy

**Effective Date: January 2026**

## 1. What We Collect

### From You Directly
- Email address (for account)
- Payment information (via Stripe)
- Decision payloads you submit

### Automatically
- IP addresses
- Request timestamps
- API usage metrics

## 2. How We Use Data

### Decision Payloads
- Hashed for chain integrity
- Stored for your retrieval
- **Never inspected semantically**
- **Never used for training**
- **Never shared with third parties**

### Account Data
- Authentication
- Billing
- Support
- Usage analytics

## 3. Data Isolation

Your decision data is:
- Isolated at the organization level
- Never joined with other organizations
- Accessible only via your API keys

## 4. Third Parties

We use:
- Stripe (payments)
- AWS (infrastructure)
- Cloudflare (CDN, DDoS)

We do NOT:
- Sell data
- Share with advertisers
- Provide to AI training

## 5. Your Rights

You can:
- Export all data at any time
- Request account deletion
- Access your records via API

## 6. Retention

- Active accounts: Retained per plan
- Deleted accounts: 30-day export window
- Proofs: Verifiable forever (even after deletion)

## 7. Security

- Encryption in transit (TLS 1.3)
- Encryption at rest (AES-256)
- Access logging
- Regular security audits

## 8. GDPR Note

For EU users:
- We are a data processor
- You are the data controller
- DPA available on request
