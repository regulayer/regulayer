# Brand vs. Method

**The Vital Distinction**

## The Brand: "Regulayer™"
- Owned by: Regulayer Inc.
- Represents: The Commercial Product, The SaaS API, The Support Contract.
- Control: Centralized.

## The Method: "Regulayer Evidence Standard"
- Owned by: The Ecosystem (governed by Charter).
- Represents: The JSON Schema, The Hash Chain Logic, The Verification Math.
- Control: Decentralized / Frozen.

## Usage
- You can say: "We verified this using the Regulayer Method."
- You cannot say: "We are partnered with Regulayer" (unless you have a contract with the Brand).
