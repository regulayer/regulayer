# Disclaimer Inheritance

**Viral Responsibility**

Any entity that builds a product ON TOP of Regulayer (e.g., an Audit Dashboard, an AI Compliance Tool) **MUST** visibly display the core negatives:

1.  **"Not an AI Safety Certification"**
2.  **"Not a Legal Compliance Guarantee"**

## Implementation
These disclaimers must appear in:
- The End User License Agreement (EULA).
- The "Help" or "About" section of the software.
- Any generated report footer.

## Enforcement Mechanisms
Disclaimers are **not optional**; omission constitutes misrepresentation.

1.  **Trademark Enforcement**: Use of the "Regulayer" brand is conditional on these disclaimers. Violation = revocation of brand rights.
2.  **Contractual Enforcement**: Partner/Reseller contracts contain explicit breach clauses for failure to disclaim.
3.  **Documentation Requirement**: Forks wishing to claim "Compatibility" must include these notices.
4.  **Public Rebuttal**: We reserve the right to publicly correct any entity that omits these disclaimers to imply false authority.
