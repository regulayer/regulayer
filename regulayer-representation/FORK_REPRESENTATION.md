# Fork Representation

**Rights and Limits of Forks**

## 1. Right to Implement
Anyone is free to implement the **Regulayer Evidence Standard**. This is the "Method".

## 2. Brand Protection
Forks **MUST NOT** use the name "Regulayer" in a way that implies they are the official entity.
- **Allowed**: "OpenProof: A specific implementation of the Regulayer Standard."
- **Forbidden**: "Regulayer Community Edition." (Unless authorized).

## 3. Trust Model Divergence
If a fork alters the verification logic (e.g., changes the hash algorithm or validation rules), it **MUST NOT** claim compatibility with the Regulayer Standard. It must declare itself a new Standard.
