# Trust Freeze Zones

**The Untouchable Core**

The following components are **FROZEN**. They cannot be modified in the V1 Standard. Future improvements must happen in V2, V3, etc., leaving V1 functional forever.

1.  **Proof Bundle Format V1**: The JSON schema defined in `regulayer-reference`.
2.  **Hash Algorithms**: SHA-256 for Payload and Record hashing.
3.  **Meaning of "VALID"**: Integrity + Authenticity.
4.  **Offline Semantics**: Support for air-gapped verification.
5.  **Non-Endorsement**: The neutrality of the standard.

Any attempt to modify these within the context of "V1" is considered a hostile fork.
