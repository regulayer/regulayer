# Change Classes

**Classification of Proposed Changes**

All changes to the Regulayer Standard must be classified before discussion.

| Class | Type | Examples | Allowed? | Process |
| :--- | :--- | :--- | :--- | :--- |
| **Class 0** | **FROZEN** | Hash semantics, Meaning of VALID, Claims of v1.x | ❌ **NEVER** | N/A |
| **Class 1** | **Additive** | New metadata fields, new storage adapters | ✅ Yes | Standard RFC |
| **Class 2** | **Optional** | UI Overlays, Helper tools | ✅ Yes | Fast Track |
| **Class 3** | **Operational** | Billing, Rate limits, Company policies | ✅ Yes | Internal Company Decision |
| **Class 4** | **Experimental** | Draft specs (v2-beta) | ✅ Yes | Sandbox Only |
| **Class X** | **Breaking** | Redefining "Verified", changing hash algo for v1 | ❌ **NEVER** | **VETO** |

## Automatic Veto
Any change classified as **Class 0** or **Class X** is automatically rejected by the Governance Charter. No vote can overturn this.
