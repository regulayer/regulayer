# Regulayer Open Governance Model

**Constitution of the Standard**

This module defines the rules that bind Regulayer. It ensures that the system remains a neutral method of verification, regardless of the fate or intent of its creators.

## Key Documents
- **GOVERNANCE_CHARTER.md**: The "Constitution". Why we exist (and what we don't do).
- **AUTHORITY_LAYERS.md**: Who can do what.
- **CHANGE_CLASSES.md**: What can change, and what is frozen forever.
- **STEWARDSHIP_TRANSITION.md**: What happens if the vendor disappears.

## The Goal
To create a system that is **Governable without Power**.
We can maintain it, but we cannot manipulate it.
