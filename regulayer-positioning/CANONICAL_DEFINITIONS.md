# Canonical Definitions

**Glossary of Terms for Legal and Technical Use**

| Term | Definition |
| :--- | :--- |
| **Record** | A digital artifact containing a payload, metadata, and a cryptographic signature. |
| **Proof Bundle** | A self-contained JSON file sufficient to verify a Record without external API access (except public keys). |
| **Decision** | The logical event being recorded. One Decision equates to one Record. |
| **Verification** | The mathematical process of checking hashes, signatures, and chain links against a standard. |
| **Authoritative Key** | A cryptographic key publicly authorized by an entity to sign Records on its behalf. |
| **Time Anchor** | A reference to an external, immutable ledger (e.g., Blockchain) used to prove a Record existed before a certain time. |
