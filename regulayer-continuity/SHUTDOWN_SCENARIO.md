# Shutdown Scenario

**Event**: Regulayer Inc. ceases operations and shuts down all servers.

**Impact Analysis**:
- **Verification**: ✅ **UNAFFECTED**. Verification is done locally or via independent tools using public keys.
- **New Recording**: ⚠️ **User-Hosted**. Users must switch to self-hosted Recorders (Regulayer is open source).
- **Time Anchoring**: ⚠️ **Degraded**. If Regulayer ran the time anchor, users must switch to public blockchain anchors directly.

**Trust Verdict**: History remains verified. New history requires self-hosting.
